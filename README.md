## 1. Project Overview

This project proposes and demonstrates an end-to-end predictive modeling framework for forecasting agricultural crop yields using machine learning techniques.

The framework focuses on understanding agricultural factors, identifying relevant features, developing predictive models, evaluating model performance, and applying the same methodology across different agribusiness scenarios.

The project uses a **synthetic dataset containing 60 districts across 14 seasons (2010–2023)**. Therefore, the results demonstrate the behavior of the proposed methodology and do not represent actual agricultural production figures.

The framework can be adapted to real-world agricultural datasets by replacing the simulation step with actual data.

## 2. Project Objectives

- Develop a structured predictive modeling framework for agricultural yield forecasting.
- Identify important agricultural features influencing crop production.

- Train and compare multiple machine learning models.

## 5. Technical Implementation

### Data Simulation and Preparation
- Generated simulated agricultural data.
- Incorporated non-linear rainfall response.
- Modeled diminishing fertilizer returns.
- Included heat stress and dry-spell effects.
- Introduced missing values, outliers, and duplicate records.

### Data Cleaning and Exploratory Analysis
- Data quality assessment.
- Missing-value handling.
- Outlier and duplicate detection.
- Statistical summaries.
- Distribution and trend analysis.
- Correlation analysis.

### Feature Engineering and Selection
- Lagged yield features.
- Interaction variables.
- Squared fertilizer features.
- Heat and dry-spell interaction.
- Trend variables.
- Correlation filtering.
- Variance Inflation Factor (VIF).
- LASSO-based feature selection.

Eight modeling approaches are included:

## 6. Model Performance and Results

The following results were obtained on the simulated test seasons (2022–2023).

| Model | Test RMSE (t/ha) | Test R-squared |
|---|---:|---:|
| Baseline (Last-season yield) | 1.088 | -0.70 |
| LASSO | 0.678 | 0.34 |
| Random Forest (Tuned) | 0.474 | 0.68 |
| **XGBoost (Tuned)** | **0.410** | **0.76** |

### Key Findings

- Tuned XGBoost achieved the lowest test RMSE of **0.410 t/ha**.
- XGBoost reduced test error by approximately **62%** compared with the baseline.
- Spatial cross-validation achieved an RMSE of 0.44 t/ha and R-squared of 0.69.
- Conformal prediction intervals achieved 92.4% coverage against a 90% target.
- Fertilizer gains flattened near 100 kg/ha under normal rainfall conditions.
- Drought conditions reduced yield by approximately 1.1 t/ha in the simulation.
- The pipeline reduced error against the baseline by 58% to 64% across maize, sugarcane, and smallholder scenarios.

**Note:** These are simulation results, not validated real-world agricultural performance measurements.

## 9. Universal Applicability

The framework is designed to support different agricultural scenarios.

The same overall modeling workflow can be adapted to:

- Maize production.
- Sugarcane production.
- Smallholder farming with limited data.
- Different crop types and geographical regions.
- Agricultural resource and supply-chain planning.

Only the dataset and relevant feature library need to be adjusted for a new scenario.

## 10. Limitations

- The project uses simulated data rather than actual farm records.
- Real-world prediction accuracy must be evaluated using actual agricultural datasets.
- Extreme weather events and changing climate conditions may affect model reliability.
- Prediction intervals must be validated for coverage on each new dataset.
- Continuous monitoring and model retraining are important for long-term reliability.
